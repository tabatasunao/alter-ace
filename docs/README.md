## Accuracy checks

- [reference.md](reference.md) is generated by `npm run docs`. Do not edit it by hand.
- `npm test` (`tests/docs.test.ts`) fails when `reference.md` does not match the data, when a relative link or `#anchor` in these pages is broken, or when a page in `docs/` is not linked from this index.
